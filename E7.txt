EXPERIMENT 7

Python Application with MongoDB

Aim: Build a simple Tkinter GUI to insert and display student records in
MongoDB.

1.  Install package

pip install pymongo

2.  Python program (save as app.py)

import tkinter as tk
from tkinter import messagebox
from pymongo import MongoClient

col = MongoClient('mongodb://localhost:27017/').collegeDB.students

def insert():
    name = name_box.get()
    roll = roll_box.get()
    col.insert_one({'name': name, 'roll': roll})
    messagebox.showinfo('Success', 'Student added')

def show():
    output.delete('1.0', tk.END)
    for s in col.find():
        output.insert(tk.END, f"{s['name']} - {s['roll']}\n")

app = tk.Tk()
app.title('MongoDB Student App')

tk.Label(app, text='Name').pack()
name_box = tk.Entry(app)
name_box.pack()

tk.Label(app, text='Roll No').pack()
roll_box = tk.Entry(app)
roll_box.pack()

tk.Button(app, text='Insert', command=insert).pack()
tk.Button(app, text='Show Students', command=show).pack()

output = tk.Text(app, width=35, height=6)
output.pack()

app.mainloop()

3.  Run

python app.py

4.  Sample output in GUI

Ravi - 101 Anita - 102

Result / Note

Expected: the GUI accepts a name and roll number, saves the record to
collegeDB.students, and lists saved students. MongoDB server must be
running locally. The original four-field form is simplified to two
fields for faster exam typing.
